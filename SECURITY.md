# Security Policy

## Reporting a vulnerability

Please report a suspected or confirmed security vulnerability privately, through GitHub Security Advisories:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Submit the advisory.

The report is visible only to the maintainers. Include a description of the issue, the affected versions, steps to reproduce, the potential impact and, optionally, a suggested fix.

Low-severity issues can be reported in public GitHub issues. If you are not sure, report privately. The [Apache severity rating](https://security.apache.org/blog/severityrating/) can help you judge.

## Supported versions

Security fixes go into the latest release. Please upgrade to it to receive them.

## Disclosure

We follow coordinated disclosure: we agree on a timeline with the reporter, publish once a fix or mitigation is available, and credit the reporter unless they ask to stay anonymous.

This policy follows the one of the other GridFM projects, e.g. [gridfm-datakit](https://github.com/gridfm/gridfm-datakit/blob/main/SECURITY.md).
